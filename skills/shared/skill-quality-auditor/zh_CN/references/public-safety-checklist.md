# 公开安全检查

Agentarium 是公开仓库。审计时必须检查 Skill、参考材料和样例中是否包含不应公开的信息。

## 阻断项

发现以下内容应标为 BLOCKER：

- API key、token、cookie、密码、私钥。
- `.env` 内容或认证文件内容。
- 私有仓库 URL。
- 内部 host、内网 IP、客户名称或客户数据。
- 未脱敏截图说明。
- 个人账号、邮箱、机器名或绝对路径，除非是明显占位符。

## 高风险项

发现以下内容通常标为 HIGH：

- 大段原始日志，包含环境细节。
- 真实项目路径或组织名。
- 可识别的业务数据。
- 声称已经公开发布但没有公开链接或占位说明。

## 推荐写法

- 使用 `<redacted>`、`<public-repo-url>`、`<project-root>` 这类占位符。
- 示例中优先使用相对路径。
- 截图先用占位说明，确认脱敏后再提交。
- 不把本地机器状态、用户目录、命令历史当作公开证据。
