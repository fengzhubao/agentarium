# 助手任务提示词模板

把下面模板复制给对应助手，并替换尖括号内容。

```text
你负责 <任务名称>，当前不是独占整个仓库，还有其他助手在不同 worktree 中并行开发。

仓库：<repo>
分支：<branch>
Worktree：<worktree-path>
目标：<goal>

允许修改：
- <path 1>
- <path 2>

禁止修改：
- <path 1>
- <path 2>

共享依赖：
- <dependency 1>

验收命令：
- <command 1>
- <command 2>

工作要求：
- 只在允许范围内修改文件。
- 不要回滚他人改动。
- 如果发现必须修改共享文件，先停止并说明原因。
- 完成后给出改动摘要、验证结果、风险和后续建议。
```
