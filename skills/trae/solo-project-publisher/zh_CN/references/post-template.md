# 发帖模板

## TRAE SOLO 技能创作赛

```markdown
# 〖Skill 创作〗<Skill 名称或一句话描述>

## 1、Skill简介

<用一两句话说明 Skill 叫什么，解决什么问题，实现什么效果，适合谁用。>

## 2、使用场景

<真实场景，不要只写泛泛用途。>

## 3、创作过程

<展示使用 TRAE SOLO 创作 Skill 的关键过程，可包含关键提示词、配置、截图或工作流说明。>

## 4、使用步骤

1. <输入或触发方式>
2. <读取或分析哪些材料>
3. <生成哪些结果>
4. <如何检查或迭代>

## 5、效果展示

- 使用前：<使用前状态>
- 使用后：<使用后产物>
- 证据：<截图、文件、命令、链接>

## 6、Skill 链接

- 源码：<链接>
- Skill 市场：<如有则填写>

## 7、总结与思考

<收获、最满意的地方、后续优化方向，以及希望读者反馈的问题。>
```

## 语气要求

- 直接、具体。
- 多写真实步骤和产物，少写口号。
- 关键结论要容易验证。
- 缺截图或链接时保留占位，不要编造。

## 发布前占位检查

发布前至少检查这些占位是否处理：

- `[待补：Skill 链接]`
- `[待补：源码链接]`
- `[待补：截图]`
- `[待补：使用前后对比]`
- `[待补：公开安全检查]`
