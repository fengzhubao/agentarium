# 证据检查清单

## 可用证据

- 文件路径和简短说明。
- Git 状态或改动差异摘要。
- 命令名称和关键输出行。
- 生成物。
- 截图或录屏。
- 公开源码链接或 Skill 市场链接。
- 使用前后对比。

## 公开安全

不要暴露：

- Token、密码、Cookie、API Key、SSH Key、认证文件。
- 个人姓名、账号、邮箱、手机号、头像、用户标签或个人资料链接。
- 内部主机名或客户数据。
- 未经允许的私有仓库链接。
- 不必要的本地绝对路径。
- 包含无关机器或账号细节的大段原始日志。

## 复查问题

- 没有私有上下文的读者能否理解这个场景？
- 每个重要结论是否都有证据？
- 占位项是否清楚标记？
- 已完成内容和后续计划是否分开？
- 是否满足目标渠道要求的正文结构？

## 最小可发布证据组合

如果时间很紧，至少准备：

- 一张 TRAE SOLO 使用 Skill 的截图。
- 一个 Skill 包或源码链接。
- 一个使用前后对比：目录变化、生成文件或输出草稿。
- 一段发布前安全检查结论。
