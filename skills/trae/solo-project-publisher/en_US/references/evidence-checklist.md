# Evidence Checklist

## Useful Evidence

- File paths with short descriptions.
- Git status or diff summary.
- Command names and key output lines.
- Generated artifacts.
- Screenshots or screen recordings.
- Public source link or Skill marketplace link.
- Before/after comparison.

## Public Safety

Do not expose:

- Tokens, passwords, cookies, API keys, SSH keys, auth files.
- Internal hostnames or customer data.
- Private repository links unless explicitly allowed.
- Unnecessary local absolute paths.
- Large raw logs with unrelated machine or account details.

## Review Questions

- Can readers understand the scenario without private context?
- Is every important claim backed by evidence?
- Are placeholders clearly marked?
- Are completed results separated from planned follow-ups?
- Does the post satisfy the target channel's required structure?

## Minimal Publishable Evidence Set

If time is short, prepare at least:

- One screenshot of TRAE SOLO using the Skill.
- One Skill package or source link.
- One before/after comparison: directory change, generated file, or output draft.
- One public-safety review note.
