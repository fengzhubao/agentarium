# Post Template

## Default English Community Post

Use this template when the target audience is English-speaking or when no Chinese contest format is required.

```markdown
# <Skill Name>: <One-Line Result>

## Skill Introduction

<Explain what the Skill is, what problem it solves, what result it produces, and who it is for.>

## Use Scenario

<Use a real scenario. Avoid generic claims.>

## Creation Process

<Show the key process of creating the Skill. Include prompts, configuration, screenshots, or workflow notes if available.>

## Usage Steps

1. <Input or trigger>
2. <What materials are read or analyzed>
3. <What results are generated>
4. <How to review or iterate>

## Results

- Before: <state before use>
- After: <result after use>
- Evidence: <screenshots, files, commands, links>

## Skill Link

- Source: <link>
- Marketplace: <link, if available>

## Summary And Reflection

<Lessons learned, strongest point, next improvements, and a specific feedback question for readers.>
```

<真实场景，不要只写泛泛用途。>

## Tone

- Be direct and concrete.
- Prefer real steps and artifacts over slogans.
- Keep key claims easy to verify.
- Use placeholders for missing screenshots or links instead of inventing them.

## Pre-Publish Placeholder Check

Before publishing, check:

- `[TODO: Skill link]`
- `[TODO: source link]`
- `[TODO: screenshot]`
- `[TODO: before/after comparison]`
- `[TODO: public-safety check]`
